# Идея №1: «Машина времени-35» (Веб-дашборд + Парсинг)

Суть: Интерактивная лента времени, которая показывает, как менялись технологии в нефтянке и в Сириусе за 35 лет.

Как работает: Вы парсите (или просто забиваете вручную в JSON) 35 ключевых событий.

Фишка: Слева бегунок (слайдер). Тянешь его — на экране меняются графики: в 1991-м — первые вышки, в 2010-м — цифровые двойники, в 2026-м — ваш проект.

Технически: Python + Flask отрисовывают страницу, а на фронте вы используете библиотеку Chart.js, чтобы рисовать «нефтяной баррель» растущим вместе с годами.

Итог: идея та же (слайдер года → карточки + Chart.js), стек и UI уже зафиксированы в коде — новые фичи только поверх текущих паттернов.

## Правила стиля кода (чтобы не ломать merge request)

**Самое важное:** пиши код в том же стиле, что уже в репозитории. Большой рефакторинг «под красоту» = конфликты с чужими MR.

### Backend (`app.py`, `scripts/*.py`)
- `from __future__ import annotations`, `Path`, короткие функции, docstring у скриптов с командой запуска
- Данные через `json.loads(...read_text(encoding="utf-8"))` / `.write_text(..., ensure_ascii=False, indent=2)`
- События: поля `year`, `title`, `desc`, `source`, `url`, `oilPrice`, `techIndex`, `barrelsHint`, опционально `productionMt`, `image`
- Сириус: править **только** `data/sirius_events.json`, не хардкодить список в двух местах

### Frontend JS (`static/js/app.js`)
- Один IIFE `(() => { ... })();` — без модулей/React/сборщика
- Константы сверху (`MIN_YEAR`, `MILESTONES_*`), DOM через `getElementById`
- Состояние — `let` в замыкании; логика по именованным `function`
- Вкладки: `currentView` + `data-view` на `body`; не плодить параллельные «приложения»

### CSS (`static/css/style.css`)
- Тема через CSS-переменные; Сириус — `body[data-view="sirius"] { ... }`
- Не переименовывать существующие классы без крайней нужды
- Не переформатировать весь файл — только нужный блок

### HTML (`templates/index.html`)
- Сохранять id элементов (`year-slider`, `lukoil-feed`, `sirius-feed`, `oil-chart`, …)
- Новые блоки — рядом с родственными, теми же классами/разметкой

### Git / MR
- Маленькие MR: одна фича или один баг
- Не коммитить `__pycache__`, временные debug-файлы, conflict markers в JSON
- Перед MR: валидный `history.json`, обе вкладки открываются, `/api/data` отвечает
- Не делать `git format` / массовый prettier по чужим файлам

- [ ] JSON валиден, без `<<<<<<<`
- [ ] Стиль как у соседнего кода (отступы, имена, структура)
- [ ] Лукойл и Сириус работают после изменений
